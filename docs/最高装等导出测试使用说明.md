# WoWLookExport3 最高装等导出测试使用说明

适用版本：WoWLookExport3 v3.3.3  
测试目标：确认每件装备导出的数据是其当前赛季实际可获得的最高版本，同时保留冒险指南原始掉落版本。

## 1. 当前配置口径

当前 `SeasonConfig.lua` 根据本地 KeystoneLoot 2.10.1（WoW 12.0.7 Build 68232）的规则配置：

- 当前赛季编号：16；
- 大秘境和常规团本的普通护甲：正常神话轨道最终档，目标装等 289；
- 当前赛季所有武器槽装备：使用虚空铸造史诗模板，目标装等 298；
- 当前赛季所有饰品槽装备：使用虚空铸造史诗模板，目标装等 298；
- 不存在史诗版本的团本装备：退回其实际存在的最高难度轨道；
- 孢陨幽境：使用独立的史诗难度固定 Bonus ID；
- 明确不可升级的物品：保留实际掉落版本。

因此导出结果出现 289 和 298 两档是正常现象：普通护甲通常为289，武器和饰品应通过虚空铸造史诗模板达到298。虚空铸造不是普通神话 6/6；若链接继续使用 `12806`，客户端只会解析为289，不能发布。

## 2. 安装测试版插件

1. 退出魔兽世界客户端。
2. 备份原来的 `World of Warcraft/_retail_/Interface/AddOns/WoWLookExport3`。
3. 将项目中的整个 `addon/WoWLookExport3` 文件夹复制到游戏插件目录。
4. 确认插件目录中同时存在：
   - `SeasonConfig.lua`
   - `WoWLookExport3.lua`
   - `WoWLookExport3.toc`
5. 启动游戏，在插件列表中启用 WoWLookExport3。

进入角色后，聊天框应显示：

```text
[WoWLookExport3] v3.3.3 已加载。输入 /wowlook（或 /wle）开始导出最高可获得装等。
```

如果没有显示 v3.3.3，说明游戏加载的不是这次修改后的目录。

## 3. 游戏内执行导出

v3.3.3 使用真实虚空铸造链接模板生成武器和饰品的 298 版本，并保留此前的构建号读取和指令异常保护修复。

先清除旧结果：

```text
/wowlook reset
/reload
```

重新进入游戏后执行：

```text
/wowlook
```

导出会依次执行：

1. 识别当前赛季地下城和团本；
2. 扫描首领掉落；
3. 补抓职业和专精归属；
4. 检查团本装备实际存在的最高难度；
5. 构造最高档装备链接；
6. 用游戏 API和 Tooltip双重验证装等；
7. 保存原始版本和最高版本。

装备较多时需要等待，不要在完成提示出现前 `/reload`。

完成后应看到类似：

```text
最高档完成：成功 N 件，失败 0 件
导出完成：地下城 8，团本 N，装备 N，最高档成功 N，最高档失败 0 ...
```

查看状态：

```text
/wowlook status
```

必须重点确认：

- `最高档失败: 0`；
- 最高档成功数等于装备总数；
- 没有显示 `赛季配置错误`；
- 没有大量 `target_item_level_mismatch`。

最后执行：

```text
/reload
```

这一步会把结果写入 SavedVariables。

## 4. 找到导出文件

导出文件通常位于：

```text
World of Warcraft/_retail_/WTF/Account/<账号>/SavedVariables/WoWLookExport3.lua
```

把该文件复制到项目根目录，建议命名为：

```text
WoWLookExport3-v3.3-test.lua
```

不要直接覆盖旧的正式导出文件，确认正确后再替换。

## 5. 运行自动检查

在项目根目录执行静态检查：

```powershell
node scripts/test-max-item-level-export.js --static
```

预期结果：

```text
静态检查通过：配置、加载顺序、验证门禁和双版本字段完整。
```

检查游戏导出数据：

```powershell
node scripts/test-max-item-level-export.js --input WoWLookExport3-v3.3-test.lua
```

预期结果：

```text
导出数据检查通过：N 件装备全部具有有效最高档版本。
最高装等分布：{...}
```

只要有一件装备状态失败、顶层装等与最高版本不一致，命令就会返回失败并列出装备 ID和原因。

## 6. 测试转换脚本

先输出到临时目录，避免覆盖正式 COS 数据：

```powershell
node scripts/parse-export.js `
  --input WoWLookExport3-v3.3-test.lua `
  --output output/max-item-level-test/data `
  --assets output/max-item-level-test/assets `
  --skip-icon-download true
```

转换开始时应显示：

```text
最高装等验证通过：N 件
最高装等状态：{"ok":N}
```

如果最高版本有任何错误，转换脚本会停止，不会生成可发布的正式数据。

## 7. 人工抽查数据

自动检查通过后，至少抽查以下装备：

- 地下城护甲一件；
- 地下城武器一件；
- 地下城饰品一件；
- 团本普通装备一件；
- 团本稀有或特殊装备一件；
- 戒指一件；
- 项链一件；
- 孢陨幽境装备一件；
- 明确不可升级装备（当前配置为物品 ID `268280`）。

在导出 JSON 中，每件普通装备应包含：

```json
{
  "itemLevel": 298,
  "dropVersion": {
    "status": "ok",
    "itemLevel": 269
  },
  "maxVersion": {
    "status": "ok",
    "itemLevel": 298,
    "expectedItemLevel": 298,
    "ruleSource": "voidforged_myth",
    "voidforged": true,
    "itemContext": 35
  }
}
```

上例适用于武器或饰品。普通护甲的 `maxVersion.itemLevel` 当前应为289。重点检查：

1. `dropVersion` 是冒险指南原始档位；
2. `maxVersion` 是最高可获得档位；
3. 顶层 `itemLevel` 等于 `maxVersion.itemLevel`；
4. 顶层 `link` 等于 `maxVersion.link`；
5. 主属性、副属性、耐力、护甲和武器伤害随装等正确提高；
6. 饰品装备/使用特效没有消失；
7. 装备名称、图标、部位和来源没有变化。

虚空铸造链接还必须满足：

- 物品上下文为 `35`；
- 公共 Bonus ID 包含 `13440`、`6652`、`13654`；
- 饰品额外包含 `12699`；
- 武器额外包含 `12701`；
- Tooltip 显示“晋升虚空铸造：史诗”。

真实饰品参考链接（物品 ID `193718`）：

```text
item:193718::::::::90:270::35:4:13440:6652:12699:13654
```

## 8. 游戏内 Tooltip 对照

对抽查装备，把 `maxVersion.link` 放回游戏聊天框或通过调试工具显示 Tooltip，对比导出内容：

- 装等一致；
- 升级轨道一致；
- 主副属性数值一致；
- 饰品和武器特效文本一致；
- 戒指/项链的赛季属性和插槽规则正确。

这是最终真实性验证。Node 脚本能验证数据内部一致性，但不能替代游戏客户端对 Bonus ID的真实解释。

## 9. 常见失败状态

### `target_item_level_mismatch`

生成链接的实际装等与赛季配置不一致。常见原因：目标装等或轨道 Bonus ID过期。不要发布，先更新 `SeasonConfig.lua`。

### `bonus_mapping_missing`

基础装等到目标装等的差值超出现有映射范围。记录装备 ID、基础装等和目标装等后扩展映射。

### `tooltip_unavailable`

客户端尚未缓存生成后的链接。重新执行一次导出；如果始终失败，再检查链接格式或特殊装备规则。

### `item_identity_mismatch`

生成链接解析成了错误装备。属于严重错误，必须停止发布。

### `no_upgrade_rule`

没有找到装备的实际最高难度或升级轨道。检查该装备的来源和团本难度扫描结果。

### `fixed_version_below_drop_level`

特殊来源固定 Bonus ID生成的版本反而低于原始掉落版本。说明特殊规则过期。

## 10. 通过标准

本轮测试只有同时满足以下条件才算通过：

- 游戏内导出完成且最高档失败数为 0；
- 自动导出检查通过；
- 转换脚本通过并生成临时数据；
- 普通护甲达到配置的正常最高轨道（当前289）；
- 所有武器槽和饰品槽装备达到298，链接上下文为 `35` 且包含虚空铸造史诗标记 `13654`；
- 可进入史诗难度的团本装备达到神话轨道最高档；
- 特殊来源和不可升级装备符合实际规则；
- 抽查装备的游戏 Tooltip 与导出属性完全一致；
- 原始掉落版本仍然存在且来源没有丢失。

如有失败，请保留以下信息：装备 ID、装备名称、来源、`dropVersion`、`maxVersion`、游戏内 Tooltip 截图和 `/wowlook status` 结果。根据这些信息可以判断应调整通用轨道配置还是增加单件特殊规则。
