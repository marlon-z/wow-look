# WCL COS `data-12.1` Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restore the main mini-program's WCL leaderboard presets from COS, publish future data to `data-12.1`, and audit every imported WCL item against the local 12.1 equipment library.

**Architecture:** WCL keeps a dedicated COS base URL and data directory, separate from the fully local equipment-data loader. GitHub Actions continues to select the three stalest specs per run and uploads their generated data to the new directory. The mini-program opens immediately and independently loads the chosen spec's index and content file; missing early-rollout specs show the existing empty state. A Node audit scans generated WCL files against the same local class modules consumed by the mini-program.

**Tech Stack:** WeChat Mini Program JavaScript/WXML, Node.js assertion tests, GitHub Actions, Tencent COS, Warcraft Logs API.
