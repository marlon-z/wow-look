# 4.4.x Crafted Equipment Data Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Generate `cos-upload/data-4.4.x` by copying `data-4.3.x` and injecting validated crafted equipment from `WoWLookCraftExport`.

**Architecture:** Add a focused Node.js generator that parses the craft SavedVariables Lua table, maps crafted records into the existing class JSON shape, appends a single crafted instance per class, updates version/meta/overview, and writes JSON/JS pairs. Add a validation script that checks file count, versions, crafted item counts, and random-attribute safety.

**Tech Stack:** Node.js, JSON/CommonJS data files, WoW SavedVariables Lua-table parsing.
