# WoWLookCraftExport 使用说明

该插件用于自动导出当前版本能够制造到最高物品等级的战斗装备。

插件不写死起始装等和最高装等。它先扫描游戏订单列表中显示为“某个装等+”的战斗装备，再计算每件装备的最高制造结果，最后从全部结果中推导本版本的制造业全局最高装等。

## 安装

将整个 `WoWLookCraftExport` 文件夹复制到：

```text
World of Warcraft/_retail_/Interface/AddOns/
```

重新登录或在角色选择界面启用插件。

导出数据保存在账号级文件：

```text
World of Warcraft/_retail_/WTF/Account/<账号>/SavedVariables/WoWLookCraftExport.lua
```

## 自动扫描与导出

登录游戏后直接输入：

```text
/wowcraft scan
```

不需要前往制造订单 NPC，也不需要打开“发布制造订单”。插件会直接读取当前版本全部制造订单选项，并使用暴雪界面显示“装等+”的同一套字段判断：

- 存在有效的起始装等；
- 没有固定最高装等范围；
- 配方具有制造品质档位。

只有武器和玩家战斗栏位的护甲会进入候选。专业工具、专业配饰、消耗品、玩具和纯外观会被排除。

找到候选后，插件会自动读取配方的修改材料槽及其依赖材料，例如装等纹章所要求的火花。它以最高制造品质逐个测试完整材料组合。第一阶段求出每件装备自己的最高装等；第二阶段求出本版本所有制造装备的全局最高装等；只有达到全局最高值的装备才进入正式数据。整个过程分批执行，聊天窗口会显示进度。

## 自动失败时的手动补采

少数配方如果无法在后台取得最高结果，会保持 `automatic_maximum_pending`，不会生成伪造数据。此时才需要：

1. 在发布制造订单列表中点击一件“装等+”候选装备。
2. 在订单详情里放入当前赛季最高级的装等提升材料。
3. 把制造品质选择到最高档。
4. 将鼠标移到输出装备，确认说明框达到 `/wowcraft status` 显示的本版本最高装等。
5. 输入：

```text
/wowcraft capture
```

只有实际说明框达到本次扫描推导出的最高装等时，装备才会写入正式 `items` 数据。

## 随机属性

插件按说明框实际行数导出随机属性：

```text
+130 随机属性1
```

导出为一项可选属性；配装时用户选择一种绿字。

```text
+32 随机属性1
+32 随机属性2
```

导出为两项可选属性；配装时用户选择两种绿字。

如果说明框直接显示暴击、急速、精通或全能，则这些属性作为固定绿字导出。

## 命令

```text
/wowcraft scan
```

无需打开界面，自动扫描当前版本制造订单目录并推导最高装等。

```text
/wowcraft capture
```

手动补采自动验证失败的当前订单详情预览。

```text
/wowcraft status
```

显示推导出的最高装等、正式通过、候选、排除和错误数量。

```text
/wowcraft reset confirm
```

清空本插件全部采集数据。必须带 `confirm`，避免误操作。

```text
/wowcraft help
```

显示游戏内帮助。

## 状态说明

- `pending_maximum_preview`：已经识别为“装等+”候选，尚未计算最高结果。
- `automatic_maximum_pending`：后台遍历材料后仍未得到有效链接，需要手动复核。
- `below_derived_maximum`：该装备能够制造，但最高结果低于本版本全局最高装等。
- `accepted_maximum`：说明框已确认达到本版本全局最高装等，进入正式数据。
- `rejected`：不是可变装等装备、不是战斗装备或不属于支持的装备栏位。

插件采用失败关闭原则：物品信息、输出链接或说明框读取失败时，只记录错误，不会生成伪造的正式装备数据。

完成采集后，请执行一次 `/reload` 或正常退出游戏，让客户端把内存中的 SavedVariables 写入磁盘，再复制导出文件。
