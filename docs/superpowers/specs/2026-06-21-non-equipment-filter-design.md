# 非装备掉落过滤设计

## 目标

从 `cos-upload/data-4.3.x` 中移除冒险指南混入的坐骑、杂项代币、配方、材料及其他无法装备的记录，同时保留全部真实可装备物品。

## 规则

普通地下城/团本掉落进入数据库前必须同时满足：

- `itemClassId` 是武器（2）或护甲（4）；
- `equipLoc` 能被现有 `SLOT_MAP` 映射为有效装备部位，不能是 `unknown`；
- 原有 `ilvl > 1` 门禁继续保留。

不使用中文物品名黑名单，因为名称和本地化会变化。职业套装数据继续走独立套装构建流程。`collectionKind = "appearance"` 只表示该物品不提供2件/4件效果，不代表它无法装备；52件披风、护腕、腰带、鞋子有真实物品ID、属性和合法槽位，必须保留。

## 验证

重建后13个职业文件中不得存在未知槽位或非武器/护甲物品；原先每职业10条、合计130条垃圾记录应全部消失。套装保持117件，其中65件核心套装和52件可装备配套件，并且全部为289。
