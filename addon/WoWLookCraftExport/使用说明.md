# WoWLookCraftExport 使用说明

该插件用于导出《至暗之夜》当前赛季能够制造到 285 物品等级的战斗装备。

它不会把所有武器、护甲强行修改成 285。候选装备必须与游戏“发布制造订单”列表中的 `246+` 显示一致，最终还必须由实际制造预览说明框确认达到 285。

## 安装

将整个 `WoWLookCraftExport` 文件夹复制到：

```text
World of Warcraft/_retail_/Interface/AddOns/
```

重新登录或在角色选择界面启用插件。

导出数据保存在账号级文件：

```text
World of Warcraft/_retail_/WTF/Account/<账号>/SavedVariables/WoWLookCraftExport.lua
```

## 第一步：扫描246+候选

1. 前往制造订单 NPC。
2. 打开“发布制造订单”界面。
3. 等待装备和配方目录加载完成。
4. 输入：

```text
/wowcraft scan
```

插件会直接读取当前版本全部制造订单选项，并使用暴雪界面显示 `246+` 的同一套字段判断：

- 最低装等是 246；
- 没有固定最高装等范围；
- 配方具有制造品质档位。

只有武器和玩家战斗栏位的护甲会进入候选。专业工具、专业配饰、消耗品、玩具和纯外观会被排除。

## 第二步：采集285预览

1. 在发布制造订单列表中点击一件246+候选装备。
2. 在订单详情里放入当前赛季最高级的装等提升材料。
3. 把制造品质选择到最高档。
4. 将鼠标移到输出装备，确认说明框显示“物品等级285”。
5. 输入：

```text
/wowcraft capture
```

只有实际说明框解析到285时，装备才会写入正式 `items` 数据。若当前仍是246或其他装等，插件会提示继续配置最高制造材料，不会把该预览当作正式结果。

## 随机属性

插件按说明框实际行数导出随机属性：

```text
+130 随机属性1
```

导出为一项可选属性；配装时用户选择一种绿字。

```text
+32 随机属性1
+32 随机属性2
```

导出为两项可选属性；配装时用户选择两种绿字。

如果说明框直接显示暴击、急速、精通或全能，则这些属性作为固定绿字导出。

## 命令

```text
/wowcraft scan
```

扫描当前版本制造订单目录。

```text
/wowcraft capture
```

采集当前打开的订单详情预览。

```text
/wowcraft status
```

显示正式通过、246+候选、排除和错误数量。

```text
/wowcraft reset confirm
```

清空本插件全部采集数据。必须带 `confirm`，避免误操作。

```text
/wowcraft help
```

显示游戏内帮助。

## 状态说明

- `pending_285_preview`：已经识别为246+，尚未采集285预览。
- `preview_not_285`：当前预览未达到285，可以配置最高材料后再次采集。
- `accepted_285`：说明框已确认285，进入正式数据。
- `rejected`：不是246+、不是战斗装备或不属于支持的装备栏位。

插件采用失败关闭原则：物品信息、输出链接或说明框读取失败时，只记录错误，不会生成伪造的正式装备数据。

完成采集后，请执行一次 `/reload` 或正常退出游戏，让客户端把内存中的 SavedVariables 写入磁盘，再复制导出文件。
