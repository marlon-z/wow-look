# 配装模拟器开发方案

> 版本：至暗之夜 12.0.7 / 90 级  
> 日期：2026-06-20

---

## 一、功能概述

在小程序和 Web 端新增「配装模拟器」页面，用户可选择职业和专精，在仿游戏角色面板的界面中为每个部位选择装备，实时查看属性汇总（含百分比），并支持保存/管理多套配装方案到本地。

---

## 二、用户流程

```
首页
├── 查装备（现有功能，进入 equipment 页面）
└── 配装备（新功能，进入 build 页面）
      ├── 第一步：选择职业 + 专精
      └── 第二步：配装界面（仿游戏角色面板）
            ├── 为每个部位选择装备
            ├── 实时查看属性汇总 + 百分比
            └── 保存 / 加载 / 管理方案
```

### 3.2 交互设计

1. **点击空槽位** → 弹出半屏弹窗，展示该部位所有可选装备（按 ilvl 降序）
2. **装备筛选** → 按当前专精的 `specs` 字段过滤，只显示该专精可用的装备
3. **选中装备** → 槽位显示装备图标 + 名称 + ilvl，中间面板实时更新
4. **再次点击已选槽位** → 可更换或清除该槽位
5. **切换专精** → 保留已选装备，不可用的标红警告
6. **戒指/饰品** → 同一件装备不能同时放在两个槽位（除非 `uniqueEquipped: false`）

## 四、属性汇总计算

### 4.1 数据来源

直接从现有 `data-4.3.x/{class}.json` 的装备数据中读取：

```javascript
item.stats.primaryStats  // [{ type: "agility", name: "敏捷", value: 600 }]
item.stats.stamina        // { type: "stamina", name: "耐力", value: 1974 }
item.stats.secondary      // [{ type: "crit", name: "暴击", value: 67 }, ...]
```

### 4.2 副属性百分比转换（12.0.7 已验证）

以下转换系数来自 [Maxroll 12.0.1](https://maxroll.gg/wow/resources/stat-diminishing-returns) 和 [Icy Veins 12.0.7](https://www.icy-veins.com/wow/enhancement-shaman-pve-dps-stat-priority) 交叉验证，12.0.1 到 12.0.7 未变化：

| 副属性 | 每 1% 所需等级分 | 30% 递减阈值 |
|--------|---------------|------------|
| 暴击 | **46** | 1380 |
| 急速 | **44** | 1320 |
| 全能 | **54**（伤害/治疗 +1%，减伤 +0.5%） | 1620 |
| 精通 | **46**（基础换算相同，但效果系数因专精而异） | 1380 |

### 4.3 递减惩罚计算

当副属性等级分超过 30% 阈值时，开始递减：

| 区间 | 惩罚 |
|------|------|
| 0% ~ 30% | 无惩罚 |
| 30% ~ 39% | -10% |
| 39% ~ 47% | -20% |
| 47% ~ 54% | -30% |
| 54% ~ 61% | -40% |
| 61% ~ 106% | -50% |
| > 106% | -100%（硬上限） |

百分比计算公式（以暴击为例）：

```javascript
function calcStatPercent(rating, perPercent) {
  const rawPercent = rating / perPercent;
  // 30% 以下无惩罚，先用线性计算
  // 配装场景下很少超过 30%，暂用线性公式
  return rawPercent;
}

// 暴击百分比 = 暴击等级分 ÷ 46
// 急速百分比 = 急速等级分 ÷ 44
// 全能百分比 = 全能等级分 ÷ 54
```

### 4.4 精通百分比（通过插件导出系数）

精通的特殊性：46 点精通等级 = 1 点精通，但 1 点精通转化为多少 % 效果取决于专精。

**获取方式**：通过 WoW 插件 API `GetMasteryEffect()` 导出每个专精的系数。

```lua
-- GetMasteryEffect() 返回值：
-- masteryEffect:     当前精通效果百分比（已算好的最终值）
-- bonusCoefficient:  专精系数（每 1 点精通 = 多少 % 效果）
local masteryEffect, bonusCoefficient = GetMasteryEffect()
```

#### 插件导出方案

在现有 WoWLookExport3 插件中新增精通系数导出命令：

```lua
-- 新增斜杠命令 /wowmastery
-- 遍历当前角色职业的所有专精，导出 bonusCoefficient
-- 输出格式：{ specId: coefficient } 映射表
```

由于 `GetMasteryEffect()` 只能获取**当前激活专精**的数据，导出流程：
1. 玩家手动切换到每个专精，分别执行 `/wowmastery`
2. 插件累积记录所有专精的系数到 SavedVariables
3. 最终导出完整映射表

或者更高效的方案：让每个职业的玩家各贡献一次数据即可，因为同职业同专精的系数是固定的（不随装备/天赋变化）。

#### 精通系数映射表结构

导出后生成静态映射表，放入小程序/Web 代码：

```javascript
// utils/mastery-coefficients.js
const MASTERY_COEFFICIENTS = {
  // 武僧
  268: { specName: '酒仙', masteryName: '醉拳大师', coefficient: 0.194, effect: '闪避几率' },
  269: { specName: '踏风', masteryName: '连击打击', coefficient: 0.380, effect: '非重复技能伤害' },
  270: { specName: '织雾', masteryName: '氤氲之雾', coefficient: 1.700, effect: '治疗量' },
  // ... 39 个专精全部列出
};

// 精通百分比 = (精通等级分 ÷ 46) × coefficient
function calcMasteryPercent(masteryRating, specId) {
  const spec = MASTERY_COEFFICIENTS[specId];
  if (!spec) return { percent: 0, label: '未知' };
  const masteryPoints = masteryRating / 46;
  const percent = masteryPoints * spec.coefficient;
  return {
    percent,
    label: `${percent.toFixed(1)}% ${spec.effect}`,
  };
}
```

### 5.3 存储限制

- 微信小程序本地存储上限 10MB
- 每个方案的 slots 只存精简快照（id、名称、ilvl、图标、属性数值），不存完整 tooltip
- 预估单个方案约 3-5 KB，可存数百套
