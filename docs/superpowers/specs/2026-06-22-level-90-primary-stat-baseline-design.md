# 90级主属性基础值与护甲专精设计

## 目标

配装汇总不再只显示装备提供的主属性，而是显示不含种族修正的90级角色属性：

- 当前专精有效主属性基础值：620
- 基础耐力：4600
- 穿齐正确护甲时应用当前专精的5%护甲专精加成

## 统计范围

只显示当前专精实际使用的力量、敏捷或智力，不显示该专精无效的其他主属性。种族、天赋、Buff、附魔和宝石仍不计算。

## 专精规则

每个专精配置：

- 有效主属性：`strength`、`agility` 或 `intellect`
- 正确护甲类型：`cloth`、`leather`、`mail` 或 `plate`
- 护甲专精加成目标：有效主属性或耐力

坦克专精的护甲专精目标为耐力：鲜血、防护战、防护骑、酒仙、守护、复仇。其他专精的护甲专精目标为有效主属性。

## 穿齐正确护甲的判定

以下8个护甲槽必须全部有装备，并且每件都属于专精要求的护甲类型：

```text
头部、肩部、胸部、护腕、手部、腰部、腿部、脚部
```

披风、项链、戒指、饰品和武器不参与判定。

新保存的配装快照保留 `armorType`。旧快照缺少该字段时，允许从 `itemSubType` 的“布甲/皮甲/锁甲/板甲”名称兼容识别；无法识别则不授予5%加成。

## 计算与取整

未触发护甲专精：

```text
有效主属性 = 620 + 装备有效主属性
耐力 = 4600 + 装备耐力
```

触发护甲专精后：

- 非坦克：`有效主属性 = floor((620 + 装备有效主属性) × 1.05)`
- 坦克：`耐力 = floor((4600 + 装备耐力) × 1.05)`

另一项不乘1.05。取整使用向下取整，与游戏属性结算方式一致。

## 界面

配装信息继续使用现有主属性区域，但数值改为角色基础值加装备值后的结果。备注明确：包含90级职业基础值和护甲专精，不包含种族、天赋及临时加成。

## 测试

- 空配装按专精显示620有效主属性和4600耐力。
- 混合主属性装备只累计当前专精有效主属性。
- 8个护甲槽未穿齐时不触发5%。
- 8个护甲槽穿齐且类型正确时触发5%。
- 任意一件护甲类型错误时不触发5%。
- 输出/治疗专精提高有效主属性；坦克专精提高耐力。
- 旧快照的中文 `itemSubType` 可以参与护甲类型判定。
