# Second-account branding design

## Goal

Brand the independent `miniprogram-second-account` copy as “艾泽拉斯装备搭配” without changing the original Mini Program, data, or functionality.

## Scope

Replace every user-facing “艾泽配装” label in the second copy: navigation titles, home/share panel text, share metadata, favorite poster text, and build/equipment page titles. The application ID and the original `miniprogram` directory remain untouched.

## Validation

Search all Mini Program source files in the second copy after the replacement. No user-facing occurrence of “艾泽配装” may remain, and every new occurrence must be “艾泽拉斯装备搭配”.
