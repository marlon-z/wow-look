# Second-account logo design

## Goal

Replace the abbreviated homepage logo in `miniprogram-second-account` with the full brand name “艾泽拉斯装备搭配”.

## Design

Keep the existing one-line gold/silver split: “艾泽拉斯” remains gold and “装备搭配” remains silver, separated by the existing divider. Reduce the title font size, inter-segment gap, and letter spacing so the eight-character name fits the current home-header width without wrapping.

## Scope

Only the second copy's `pages/index/index.wxml` and `pages/index/index.wxss` change. The original program remains untouched.
